# Hubly

El sistema de trabajo para agencias de redes sociales: lleva cada pieza de contenido de la idea al resultado y siempre responde **¿qué sigue y quién lo tiene?**

**Estado:** Fase 0, fundación. Todavía no hay aplicación que ejecutar.

- [Constitución](docs/CONSTITUCION.md): los principios que no se negocian.
- [Plan](docs/PLAN.md): fases y criterios de cierre.
- [Inventario de necesidades](docs/producto/inventario.md): qué debe resolver el producto.
- [Configuración de agentes](docs/agentes/CONFIGURACION.md): el equipo que lo construye.
